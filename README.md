# AI-Based Forest Fire Risk Detection System 🔥

An interactive, web-based simulation and educational platform designed to predict forest fire risks using environmental chemistry and Artificial Intelligence concepts. This project was developed as a Continuous Assessment (CA1) academic task.

## 🌟 Key Features
* **Real-Time AI Risk Calculator:** A dynamic simulation engine that calculates combustion probability instantly as users adjust environmental parameters via sliders.
* **Predictive Analysis Dashboard:** Features a dynamic progress bar with color-coded warning levels (Low, Moderate, High, Critical) based on scientific data.
* **Interactive Research Carousel:** A 5-topic informational slider detailing the chemistry of combustion, fuel moisture content, and toxic emissions.
* **Premium Modern UI:** Built with a dark mode theme, glassmorphism components, and high-quality visuals for an immersive user experience.

## 🧠 AI Methodology
Although this project runs entirely in the browser, it simulates core Artificial Intelligence principles:
* **Rule-Based Expert System:** The calculator uses a weighted mathematical algorithm (giving maximum weight to temperature, followed by humidity and wind speed) to simulate the logical decision-making process of an AI expert system.
* **Predictive Analysis:** Instead of detecting a fire after it starts, the system analyzes current environmental input data to predict the *future probability* of combustion.
* **Simulation Engine:** It acts as a frontend representation of a backend Machine Learning model, demonstrating how real-world AI uses weather APIs and datasets to evaluate risk.

## 💻 Technologies Used
* **HTML5:** Semantic structure and multiple interlinked research pages.
* **CSS3:** Custom styling, flexbox/grid layouts, animations, and responsive design.
* **JavaScript (ES6):** DOM manipulation, slider logic, and the real-time predictive calculation algorithm.
